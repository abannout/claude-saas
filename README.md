# claude-saas

This repo holds market research for a new B2B/B2C SaaS aimed at a specific audience (September 2026).

- **Results:** [SAAS_OPPORTUNITIES.md](SAAS_OPPORTUNITIES.md) lists 12 ideas, ranked. Each has a 2-week validation test, a marketing plan with no cold outreach, and a recommended start order.
- **Full debate:** [research/debate/](research/debate/) holds the 6-round defender-vs-critic debate, with sources.
